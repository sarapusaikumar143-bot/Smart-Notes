## 🌟 Key Features

### 📅 1. Interactive Financial Calendar
- Visual month-by-month calendar view with daily income & expense totals.
- Color-coded transaction indicators for instant cash-flow visibility.
- Single-tap day selection to inspect all transactions on any given date.

### 💳 2. Multi-Wallet Management & Balance Tracking
- Track individual balances across multiple accounts (Cash, Bank Accounts, Digital Wallets, Crypto).
- Compute total net worth automatically.
- Multi-Wallet Fund Transfer engine with real-time balance calculations.

### 🤖 3. AI Money Copilot & Expense Analyzer
- Natural language chat assistant for budgeting advice, spending trends, and financial questions.
- Smart categorization and budget health forecasting.
- Automated expense anomaly alerts.

### 📝 4. Smart Notes with Auto-Extraction
- Create detailed financial notes and memos.
- Automatic parser recognizes amounts, dates, and categories to turn notes directly into recorded transactions.

### 🗂️ 5. In-App Files Explorer & Artifact Hub
- Dedicated in-app file browser to inspect and manage all exports.
- Export transactions to **CSV** spreadsheets and formatted **Audit Statements**.
- Direct APK installer and specification inspector within the app.

### 🔒 6. 100% Offline-First & Private
- Powered by local **Room SQLite Database**.
- Optional app lock (PIN / Biometric) for maximum financial privacy.
- Zero mandatory cloud dependencies for core accounting functions.

## 🛠️ Tech Stack & Architecture

- **UI Framework:** Jetpack Compose (Material Design 3 - M3)
- **Programming Language:** Kotlin 2.0+
- **Database:** Android Room with Kotlin Symbol Processing (KSP)
- **Architecture:** Clean Architecture + MVVM (Model-View-ViewModel)
- **Reactive Streams:** Kotlin StateFlow & Coroutines
- **Target SDK:** Android 16 (API 36)
- **Minimum SDK:** Android 7.0 (API 24)

## 💻 Building from Source

To compile and build this project locally:

```bash
# Clone the repository
git clone https://github.com/sarapusaikumar143-bot/Smart-Notes.git

# Open directory
cd Smart-Notes

# Build Debug APK
./gradlew assembleDebug

# Build Production Android App Bundle (AAB)
./gradlew bundleRelease
```

The compiled APK will be located at:
`app/build/outputs/apk/debug/app-debug.apk`
